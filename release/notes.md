Vortex 3.23.1

- First public GitHub release, with anonymous automatic update checks and a consistent VortexSetup.exe installer.
- Downloads verify HTTPS destinations, complete file sizes, and SHA-256 before Velopack installs the update and restarts Vortex.
- Update failures leave the current app usable. Closing Vortex cancels a network operation safely.
- Includes the profile library, rendering and stability improvements, refined controls, animations and 12 font choices from 3.23.0.
- Existing settings and named profiles are preserved during upgrades.

Windows x64. Install VortexSetup.exe once; future releases appear in Updates. This release is unsigned.
